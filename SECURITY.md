# Security Policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch. If you use a pinned release or commit, update to a current version before reporting a suspected issue when possible.

## Reporting a vulnerability

Please do **not** open a public issue for a security vulnerability. Instead, use GitHub's [private vulnerability reporting](https://github.com/touchine-ojo/OJO-Design-Skills/security/advisories/new) for this repository.

Include a clear description, impact, reproduction steps or proof of concept, and any suggested mitigation. Maintainers will acknowledge the report, assess it, and coordinate a fix before public disclosure where appropriate.

This repository includes shell installation tooling. Please report issues involving supply-chain integrity, unsafe file handling, command injection, or privilege escalation through the private channel above.
