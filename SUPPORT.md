# Getting support

For installation, usage, or documentation questions, first check the [README](./README.md), including the client table and advanced install options.

If the answer is not there, open a [GitHub Discussion](https://github.com/touchine-ojo/OJO-Design-Skills/discussions) with:

- the AI coding client and version you are using;
- your operating system;
- the command you ran and the exact error or unexpected result; and
- the skill or documentation section involved.

Use [Issues](https://github.com/touchine-ojo/OJO-Design-Skills/issues) for confirmed bugs and concrete, scoped feature requests. Use private vulnerability reporting for security concerns; see [SECURITY.md](./SECURITY.md).
